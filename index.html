📈 Diagrama de Mollier p-h

El diagrama representa el ciclo estimado a partir de las mediciones de campo. En mezclas zeotrópicas se utiliza temperatura de rocío para superheat y temperatura de burbuja para subcooling.

Metodología

Presiones introducidas como manométricas y normalizadas a barA. El ciclo se evalúa mediante estados 1-2-3-4. El diagnóstico se expresa como patrón compatible y no como identificación definitiva de una avería.
